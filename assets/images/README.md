# Images

This folder contains all the image assets for the FitCoach AI app.

## Structure

- `icons/` - App icons and UI icons
- `illustrations/` - Onboarding illustrations and graphics
- `backgrounds/` - Background images and patterns
- `exercises/` - Exercise demonstration images
- `food/` - Food images for nutrition tracking

## Formats

- Use PNG for images with transparency
- Use JPG for photos
- Use SVG for scalable vector graphics
- Optimize images for mobile (max 2MB per image)

## Naming Convention

- Use snake_case for file names
- Be descriptive: `onboarding_gender_selection.png`
- Include size in name if multiple sizes: `icon_24.png`, `icon_48.png`
